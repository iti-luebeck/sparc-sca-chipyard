# CellIFT SRAM Taint Initialization Data
# Format: taint_group address size taint_mask
#
# This file specifies which memory addresses should be marked as tainted
# when the simulation starts. The matrices are located in DRAM at these
# addresses and are moved into the Gemmini scratchpad via DMA.
#
# For a 4x4 matrix of int8_t: 16 bytes
# For a 4x4 matrix of int32_t: 64 bytes
#
# The DIM value can vary (4, 8, 16, etc.) so we mark a large region as tainted.
# Maximum matrix size for DIM=16: 16x16 = 256 bytes (int8_t), 1024 bytes (int32_t)

# Mark matrix B *source* as tainted at 0x800001c8 (test_matrix_B in .rodata)
# For 4x4 int8_t matrix: 16 bytes
# This ensures Gemmini DMA reads tainted data directly from the source
0 800001c8 16 FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF

# Note: Matrix A (input) is NOT tainted - the computation depends on both inputs
# but we're interested in tracking how matrix B's (weight) taint propagates through the system
